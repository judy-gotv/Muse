关于

接口对应规范

以 OpenAI /v1 契约为底座标准，自有扩展只做加法、不改标准字段语义。规范版本 v1，机器可读出处：GET /v1/standard。

类别接口属性
文字POST /v1/chat/completions · POST /v1/responses原生
图片 · 同步POST /v1/images/generations · POST /v1/images/edits原生
图片 · 异步POST /v1/images/tasks自扩
视频POST /v1/videos（异步任务制）自扩
音频对话产物：chat 回执 audios[]，经 /v1/media 取用自扩
文件对话产物：chat 回执 files[{name, url}]（want_files），经 /v1/media 取用自扩
任务回执统一骨架 status / result / bytes自扩
错误分类category 九类：model_refusal · account_unavailable · auth_expired · queue_full · timeout · upstream_error · invalid_request · not_found · send_unconfirmed自扩
模型muse-spark（文字）· muse-image（图片）· muse-video（视频）自扩

恢复原始状态

账号 —

  • 清除该账号在 muse 侧保存的关于你的一切：全部记忆、全部侧边对话、工作区文件与媒体；
  • 删除是永久的、不进回收站，无法恢复；
  • 账号与登录保留，不删账号——等于让它从头开始认识你；
  • 已知边界：主聊天历史无法通过对话删除（生产不在主聊天，不受影响）；
  • 过程在主聊天里自动进行（问存量 → 下清理令 → 确认执行 → 复查裁决），约数分钟、最长约 60 分钟；结果写入账号注记与执行账。
